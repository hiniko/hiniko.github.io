Senior Software Engineer — Backend & Platform

Profile

Nearly fifteen years building software, starting with the tools I wrote to do my Linux support job. Today I build backend APIs and infrastructure day to day, reaching into data on one side and AI enablement on the other. .NET for the last two years, Go for nearly three, on PostgreSQL, messaging and Terraform/GCP.

Writing code is close to solved. The unsolved part is designing systems that stay testable, and keeping velocity without losing stability. Code has no value in itself: its value is what it enables, or what people believe it enables. I treat it as the means to that end, and manage it so it never gets in the way.

I work AI-first. Agents do most of the typing; I design the system, the gates they work inside and the checks that prove their output, and I own the calls that can't be undone.

Ask me why, in the era of AI, everything we knew about building software matters more, not less.

How I work with AI

  • Verify, don't trust. Tests and checks, not vibes.
  • Humans own the irreversible. Specs, merges, releases.
  • Specs before code.
  • Cheapest model that can do the job.
  • Encode judgement as skills, not tribal knowledge.
  • One write path, hard boundaries.

What I'm exploring

  • Hem: a true ADLC, one spec graph and one write path for agents and humans
  • Ticket-to-PR agents where only a human approves and merges
  • Multi-agent orchestration across parallel worktrees
  • Model tiering and the cost of agentic work
  • Verification gates for agent output
